# 고민지 기말 퀴즈

GitHub Pages 배포용 정적 사이트입니다.

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더(`github-pages-ready`) 안의 모든 파일과 폴더를 저장소 루트에 업로드합니다.
3. 저장소의 `Settings` > `Pages`로 이동합니다.
4. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
5. Branch를 `main`, folder를 `/ (root)`로 선택하고 저장합니다.
6. 잠시 후 표시되는 `https://계정명.github.io/저장소명/` 주소로 접속합니다.

## iPhone/iPad 홈 화면 추가

1. iPhone/iPad에서 Safari로 GitHub Pages 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 홈 화면의 아이콘으로 실행합니다.
